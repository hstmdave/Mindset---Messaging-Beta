Mindset → Salesforce live agent handoff

Reference page for the Mindset Messaging Beta. The Mindset agent is the only chat visible on load. When the agent decides the customer needs a human, it calls its escalate_to_live_agent page tool, which opens the Salesforce Embedded Messaging chat and hides the Mindset widget.

This page needs a backend. Unlike index.md, it uses the authenticated flow, so /api/mindset/token must exist and return an authToken. That endpoint cannot live on GitHub Pages — run this one from the real application. For a static host, use the anonymous setup in index.md instead.

Also register Mindset_Summary and Escalation_Reason as Custom Parameters in Salesforce Setup first — see SALESFORCE-SETUP.md.

Testing the handoff

  1. Open this page with the browser console visible.
  2. Tell the agent something it cannot resolve, or just ask for a person.
  3. The Salesforce chat should open and the Mindset widget should disappear.
  4. Check the Messaging Session record in Salesforce — the custom fields should carry the name, email and the AI-written summary.
